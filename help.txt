1. The 3 Layers of Knowledge
Layer	Technology	What It Stores	Purpose
1. Executive Profile & Verified Memories	PostgreSQL (executive_profiles, memories)
	Personality, leadership style, decision rules, communication tone, and verified 
    facts.	Core identity and ground-truth rules the AI must follow.
2. Document Knowledge Base	Vector Memory (knowledge_chunks)	Uploaded PDF 
documents and text files chunked with OpenAI embeddings.	
Semantic search across company docs, memos, and background material.
3. Relational Graph Memory	Neo4j (Optional)	Entities, categories, and connected 
memory nodes (:HAS_MEMORY, :RELATED_TO).	Links related concepts 
and cross-references past decisions and principles.
2. How Ingestion Works (Uploading Documents)
Upload: You upload a text PDF or .txt file via POST 
/api/clients/{client_id}/knowledge/upload in the Settings tab.
Chunking: The document text is parsed with pypdf and split into digestible blocks 
(~1,000–1,200 characters each).
Embedding: Each chunk is converted into a 1536-dimensional vector using 
OpenAI’s text-embedding-3-small.
Storage: Chunks and embeddings are stored in the PostgreSQL 

knowledge_chunks
 table. A summary node is also registered in relational and graph memory.
3. How Retrieval & Reasoning Works During Conversations
When a user speaks or asks a question in Talk to Agent:

mermaid
flowchart LR
    A["User Voice Input"] --> B["Whisper Transcription"]
    B --> C["LangGraph Retrieval Node"]
    C --> D1["1. Relational Profile & Memories"]
    C --> D2["2. Semantic Vector Search (Top 5 Chunks)"]
    C --> D3["3. Neo4j Graph Relationships"]
    D1 & D2 & D3 --> E["LangGraph Reason Node (GPT)"]
    E --> F["Response Generation"]
    F --> G["ElevenLabs Voice Synthesis"]
Transcription: User voice audio is transcribed via OpenAI Whisper (whisper-1).
Parallel Retrieval:
Vector Search: The user query is embedded, and cosine similarity matches the top 
5 most relevant document chunks.
Graph Search: Queries Neo4j for connected historical memories or principles.
Profile Injection: Loads the executive's explicit rules, risk tolerance, 
and communication tone.
Reasoning Prompt: All retrieved sources are injected into an integrated prompt 
to instruct GPT:
Uses documented principles over generic answers.
Transparently flags when documentation is missing rather than hallucinating facts.
Voice Synthesis: The final response is spoken back in the executive's enrolled 
voice using ElevenLabs.
